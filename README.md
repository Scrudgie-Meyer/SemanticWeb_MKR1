# Модульна контрольна робота №1

Номер у списку: **23**. Варіант завдання 2: `23 % 6 = 5` — гори
(`Q8502`) Швейцарії (`Q39`), висота (`P2044`) понад **3500 м**.

Запуск із папки:

```powershell
python -m pip install -r requirements.txt
python gen_data.py --seed 23
python build_graph.py flights.csv params.json graph.ttl
python run_queries.py
```

`build_graph.py` нормалізує та об’єднує дублікати рейсів, створює схему,
типізовані значення й RDF-реїфікацію затримок. Часті країни визначаються
за кількістю унікальних рейсів. Рейс може мати обидва спеціалізовані типи.

Запити враховують екземпляри класу гори та його підкласів. Регіон — пряме
значення `P131`; Q2 рахує унікальні об’єкти. Q1 зберігає об’єкти без сайту.
Дані Wikidata можуть змінюватися; час отримання у UTC записується в `meta.json`.
Результати: `q1.csv`, `q2.csv`, `q3.csv`; відповіді: `ANSWERS.md`.
